# Дизайн-пакет сайта

Эта папка — рабочий источник правил для дизайна сайта детейлинга в Гомеле. Она нужна агентам и разработчикам, чтобы новые экраны сохраняли одну визуальную систему и не добавляли неподтверждённые сведения о компании.

## Файлы

- [DESIGN_SPEC.md](./DESIGN_SPEC.md) — визуальная и UX-спецификация, структура страниц и критерии готовности.
- [CONTENT_QUESTIONS.md](./CONTENT_QUESTIONS.md) — вопросы владельцу проекта и список данных, необходимых для публикации.
- [ASSET_GUIDE.md](./ASSET_GUIDE.md) — правила фотографий, имён файлов, `alt` и реестр текущих изображений.
- [design-preview.html](./design-preview.html) — автономный moodboard с текущими фотографиями и примерами компонентов.
- [assets/icons/](./assets/icons/) — отдельные SVG-иконки в едином контурном стиле.

## Как просматривать moodboard

Откройте `design-preview.html` напрямую в браузере из репозитория. Изображения и SVG подключаются относительными путями из `public/images` и этой папки, поэтому файл не требует сервера.

## Статус данных

Фотографии в `public/images/reference` и текущие тексты прототипа считаются визуальной основой. Они не подтверждают факт выполнения работ, адрес, цены, сроки, гарантии или контакты. До получения ответа владельца проекта эти сведения должны оставаться `TBD` или быть заменены реальными материалами.
