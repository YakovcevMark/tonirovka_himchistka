# ПЕРВОСТЕПЕННАЯ ЗАДАЧА ПРОЕКТА

Этот документ задаёт главный критерий для всех последующих изменений сайта и работы агентов.

## Цель

Создать и поддерживать сайт-визитку, который получает максимально сильную органическую видимость в Google и Яндексе по коммерческим запросам жителей города Гомеля, связанным с:

- тонировкой автомобилей;
- химчисткой салона;
- оклейкой автомобиля антигравийной плёнкой;
- перетяжкой потолков и стоек;
- полировкой фар.

Приоритет — релевантная выдача сайта на первых позициях по этим услугам в Гомеле. Позиции не гарантируются одной настройкой: они зависят от качества страниц, подтверждённой информации о компании, технического состояния сайта, ссылок, отзывов и конкуренции.

## Обязательные правила для агентов

1. Любое изменение оценивается по тому, усиливает ли оно понятность услуг, привязку к Гомелю, доверие пользователя и техническую доступность сайта для поисковых роботов.
2. Тексты должны быть конкретными: услуга, автомобильная задача, город и следующий шаг пользователя должны быть понятны из заголовков и первого экрана.
3. Для новых страниц и секций нужно использовать семантическую HTML-структуру: один `h1`, логичные `h2`, описательные ссылки, понятные `title` и `description`.
4. Нельзя добавлять выдуманные адреса, телефоны, цены, отзывы, сертификаты, сроки или обещания результата. Используются только подтверждённые данные.
5. Нельзя делать отдельные почти одинаковые страницы только ради ключевых слов. Каждая страница должна отвечать на самостоятельный запрос и давать полезную информацию.
6. Локальные формулировки должны использовать «Гомель» естественно, без переспама и скрытого текста.
7. При добавлении изображений нужно готовить осмысленные имена файлов и `alt`, описывающий изображённую услугу.
8. До завершения задачи нужно проверять, что сайт собирается, доступен с базовым URL GitHub Pages и не получил регрессий в метаданных.

## Приоритет запросов

Основные кластеры: «тонировка авто Гомель», «химчистка салона Гомель», «антигравийная плёнка Гомель», «перетяжка потолка автомобиля Гомель», «полировка фар Гомель». Дополнительные формулировки подбираются по реальному спросу, содержанию услуг и данным Google Search Console/Яндекс Вебмастера после их подключения.

## Как принимать решения

Если техническое или визуальное решение конфликтует с этой целью, выбирается вариант, который сохраняет скорость, мобильную доступность, понятную структуру услуг и честную локальную релевантность. SEO не должно ухудшать удобство пользователя или подменять реальные сведения о компании.
