# ПЕРВОСТЕПЕННАЯ ЗАДАЧА ПРОЕКТА

Этот документ задаёт главный критерий для всех последующих изменений сайта и работы агентов.

## Цель

Создать и поддерживать сайт-визитку, который получает максимально сильную органическую видимость в Google и Яндексе по коммерческим запросам жителей города Гомеля, связанным с:

- тонировкой автомобилей;
- химчисткой салона;
- оклейкой автомобиля антигравийной плёнкой;
- перетяжкой потолков и стоек;
- полировкой фар.

Цель всего проекта — первое место сайта LDV Detailing в органической выдаче Google и Яндекса для пользователей из Гомеля по каждому из 14 запросов ниже. Этот приоритет действует при планировании и приёмке любых изменений. Фактическую позицию оцениваем по данным поиска отдельно для каждого запроса и поисковика.

## Обязательные правила для агентов

1. Любое изменение оценивается по тому, усиливает ли оно понятность услуг, привязку к Гомелю, доверие пользователя и техническую доступность сайта для поисковых роботов.
2. Тексты должны быть конкретными: услуга, автомобильная задача, город и следующий шаг пользователя должны быть понятны из заголовков и первого экрана.
3. Для новых страниц и секций нужно использовать семантическую HTML-структуру: один `h1`, логичные `h2`, описательные ссылки, понятные `title` и `description`.
4. Нельзя добавлять выдуманные адреса, телефоны, цены, отзывы, сертификаты, сроки или обещания результата. Используются только подтверждённые данные.
5. Нельзя делать отдельные почти одинаковые страницы только ради ключевых слов. Каждая страница должна отвечать на самостоятельный запрос и давать полезную информацию.
6. Локальные формулировки должны использовать «Гомель» естественно, без переспама и скрытого текста.
7. При добавлении изображений нужно готовить осмысленные имена файлов и `alt`, описывающий изображённую услугу.
8. Основной адрес сайта — `https://ldvdetailing.pro/`. Проверяйте, что обе сборки (ActiveCloud и GitHub Pages) указывают на него через canonical, а услуги и цены можно прочитать без JavaScript. После изменения адресов проверяйте редиректы, robots.txt и sitemap.xml на опубликованном сайте.

## Приоритет запросов

| Услуга | Целевые запросы для отслеживания |
| --- | --- |
| Тонировка | Затонировать машину в Гомеле недорого · Тонировка задней полусферы Гомель · Наклеить тонировку в Гомеле с гарантией · Тонировка Гомель |
| Оклейка | Оклейка авто пленкой цена · Бронирование кузова Гомель · Оклейка бронепленкой с гарантией · Оклейка Гомель |
| Полировка фар | Полировка фар в Гомеле · Полировка фар в Гомеле недорого · Полировка фар Гомель |
| Перетяжка | Перетяжка потолков в Гомеле · Цена перетяжки потолка в машине Гомель · Перетяжка потолков Гомель |

В этой студии под тонировкой понимается тонировка всей задней полусферы. Цены по типу кузова относятся к этой услуге. Владелец подтвердил гарантию 5 лет на тонировку и на оклейку кузова бронеплёнкой, а также стоимость полировки двух фар 60–120 р. На запросы «недорого» отвечаем конкретными ценами. Для бронирования кузова объясняем условия индивидуального расчёта.

Для сравнения до и после публикации сохраняйте период, поисковик, запрос, показы, клики и среднюю позицию из Google Search Console и Яндекс Вебмастера. Указывайте доступную географию отчёта. Средняя позиция за период и результат конкретного поиска из Гомеля измеряют разные вещи. Если запрос отсутствует в выгрузке, отмечайте «нет данных».

## Основной адрес при публикации

В панели хостинга настройте постоянное перенаправление с `www.ldvdetailing.pro` на `https://ldvdetailing.pro` с сохранением пути и строки запроса. Для Nginx подготовлено [правило редиректа](deploy/activecloud/www-redirect.nginx.conf) для конфигурации виртуального хоста. Публикация HTML по FTP обновляет только файлы сайта. Домашняя страница на GitHub Pages указывает на основной домен через canonical.

Для проверки выполните `curl -I "https://www.ldvdetailing.pro/robots.txt?check=seo"`. Ожидается код 301 и заголовок `Location: https://ldvdetailing.pro/robots.txt?check=seo`. Основной адрес должен возвращать файл с кодом 200.

## Как принимать решения

Если техническое или визуальное решение конфликтует с этой целью, выбирается вариант, который сохраняет скорость, мобильную доступность, понятную структуру услуг и честную локальную релевантность. SEO не должно ухудшать удобство пользователя или подменять реальные сведения о компании.
